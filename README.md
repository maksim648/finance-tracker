# Кошти — особистий фінансовий трекер

Локальний вебзастосунок на Python + SQLite з українським інтерфейсом. **Без зовнішніх бібліотек, CDN та інтернету.** Потрібен Python 3.10 або новіший.

## Запуск

1. Розпакуйте архів та відкрийте термінал у папці `finance_tracker`.
2. Виконайте:

```bash
python app.py
```

На Linux/macOS за потреби використовуйте `python3` замість `python`.
3. Відкрийте http://127.0.0.1:8000 у браузері.
4. Для зупинки натисніть Ctrl+C у терміналі.

Якщо порт зайнятий: `python app.py --port 8001`.
База `finance.sqlite3` створюється автоматично. Спочатку база порожня. Для демонстрації: `python app.py --demo` — додає явно демонстраційні операції за поточний місяць лише в порожню базу. Не використовуйте демо для реального обліку.

## Можливості

- Додавання, редагування і видалення доходів та витрат.
- 9 фіксованих категорій, дата та опис.
- Фільтр за місяцем, доходи, витрати і залишок за обраний місяць.
- Стовпчики витрат за категоріями та графік витрат за кожен день місяця з таблицею точних сум.
- Адаптивний інтерфейс та автоматична темна тема.
- Гроші зберігаються цілим числом копійок; сервер перевіряє суми та дати.
- SQL-запити параметризовані, введений текст екранується, зміни захищені токеном CSRF.

«Залишок за місяць» = доходи мінус витрати цього місяця. Це не баланс банківського рахунку. Валюта лише гривня (UAH). Дні без записаних витрат мають нуль; майбутні дні також не містять операцій, якщо їх не внесено.

## Структура

- `app.py`: HTTP-сервер, перевірка форм, SQLite та побудова HTML/SVG.
- `static/style.css`: стилі (вбудовуються сервером у сторінку).
- `test_app.py`: автоматичні тести.

## Тести

```bash
python -m unittest -v
```

## Дані та безпека

Це застосунок **для однієї людини на власному комп’ютері**, без входу та користувачів. Він слухає тільки 127.0.0.1. Не відкривайте його в інтернет, не налаштовуйте проксі чи публічний доступ без автентифікації, HTTPS та додаткової перевірки безпеки. Локальні програми та користувачі вашого комп’ютера можуть мати доступ до даних. База не зашифрована.

Для резервної копії зупиніть сервер та скопіюйте `finance.sqlite3` у захищене місце. Для відновлення зупиніть сервер і поверніть цей файл у папку проєкту. Не публікуйте базу в Git. Шлях до бази можна задати змінною середовища `FINANCE_DB`.

Це мінімальний робочий проєкт, не банківська система. Наступні можливі доповнення: власні категорії, бюджети, експорт CSV, авторизація.

## Нове: архів минулих операцій

Натисніть **Архів** у верхній навігації або відкрийте http://127.0.0.1:8000/archive.

- Архів показує операції **до першого дня поточного місяця** за локальною датою системи; поточний і майбутні місяці виключені.
- Оберіть рік, місяць, тип операції та категорію. Є пошук підрядка в описі (без урахування регістру, зокрема українською).
- Підсумки враховують всю відфільтровану вибірку; таблиця показує по 50 операцій на сторінці.
- «Відкрити місяць» переходить до огляду з графіками та можливістю редагування. Сам архів лише для читання.
- Старі операції зберігаються в тій самій таблиці SQLite: переміщення, копіювання та міграція бази не потрібні. Архів — це представлення збережених даних, а не резервна копія та не журнал версій. Видалені операції в ньому не залишаються; редагування відображає актуальні значення.

### Оновлення без втрати даних

1. Зупиніть попередній сервер (Ctrl+C).
2. Зробіть резервну копію вашого `finance.sqlite3`.
3. Замініть `app.py`, `static/style.css`, `test_app.py`, `README.md` файлами з нового архіву; **не видаляйте і не перезаписуйте `finance.sqlite3`**.
4. Запустіть `python app.py`. Якщо використовували `FINANCE_DB`, залиште той самий шлях.

Новий ZIP не містить бази даних. Якщо запускаєте нову папку, перенесіть туди свій файл бази при зупиненому сервері або задайте його шлях через `FINANCE_DB`.

## Версія 1.2: інтерактивні графіки

- **За днями:** клік по точці чи вертикальній зоні дня фільтрує історію до всіх його операцій (доходи та витрати).
- **За тижнями:** стовпчики календарних тижнів пн–нд, обрізаних межами місяця; клік показує операції цього інтервалу.
- **Накопичено:** сума витрат від початку місяця; клік по дню показує лише операції дня.
- **Топ-5 категорій:** сума й частка від усіх витрат місяця; «Решта категорій» узгоджує загальний підсумок. Розкривна таблиця містить усі категорії.
- Місячні картки та графіки не змінюються при фільтрації таблиці. Біля історії показано вибраний період і посилання **Показати весь місяць**.
- Перемикання та фільтрація виконуються через серверне перезавантаження сторінки. Не потрібні зовнішні скрипти або інтернет. Вибір дня доступний також через поле дати й таблицю точних сум.
- Перемикач режимів зберігає фільтр; зміна місяця його скидає. Успішні зміни операцій зберігають контекст.

### Однофайловий запуск

`finance_tracker.py` у корені ZIP містить весь застосунок зі стилями. Запуск: `python finance_tracker.py`. SQLite створюється поруч. Щоб використати стару історію, перенесіть `finance.sqlite3` поруч або задайте той самий `FINANCE_DB`. Не запускайте дві версії одночасно на тому самому порту.
